# Cabinet Grotesk (Indian Type Foundry, via Fontshare)

`CabinetGrotesk-Medium.woff2` (500) and `CabinetGrotesk-Bold.woff2` (700) are
the two weights the web uses, served through `next/font/local` from
`src/components/root-document.tsx` (self-hosted since 2026-10-04 — the
Fontshare stylesheet was render-blocking on every page).

Licence: ITF Free Font License (see `loyalshy-staff/assets/fonts/CabinetGrotesk-LICENSE.txt`).
It allows use in our products but **not public redistribution**: keep this
repository private, and strip these files if it ever goes public.
